stupid tokens

A free, keyless, chain-agnostic API for EVM token search and bulk USD pricing. No signup, no API key, CORS enabled.

Token identity is { chainId, address }. Addresses are case-insensitive. Native currencies use the literal address native. Responses identify chains by numeric chainId only.

Endpoints

Endpoint Description
GET /v1 Machine-readable endpoint index.
GET /v1/chains Supported chains with token counts.
GET /v1/search Search by name, symbol, or exact address, ordered by market cap.
GET /v1/tokens/{chainId}/{address} Metadata for one token.
GET /v1/prices Cacheable bulk USD prices for up to 50 tokens. POST is also accepted.
GET /health Readiness and catalog status.

Search

curl 'https://tokens.stupidtech.net/v1/search?q=usdc&chainId=8453&limit=5'

q is required (2–100 characters) and matches a case-insensitive name or symbol substring, or an exact contract address. chainId and limit (1–100, default 20) are optional. Results are ordered by stored market cap descending, with unknown caps last, and are edge-cached for up to 60 seconds.

Token Metadata

curl 'https://tokens.stupidtech.net/v1/tokens/1/0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48'

Returns the metadata object shown above, or HTTP 404 when the token is not in the catalog.

Bulk Prices

Prefer the cacheable GET form: tokens are comma-separated as chainId:address, and are sorted and deduplicated automatically. Non-canonical requests receive a 308 redirect to the canonical URL. 

curl 'https://tokens.stupidtech.net/v1/prices?tokens=1:native,8453:0x833589fcd6edb6e08f4c7c32d4f71b54bda02913'

The response is sent with Cache-Control: public, max-age=N, where N is the shortest remaining freshness across the batch. It is never longer than five minutes; a batch that has already gone stale is cached only until a refresh becomes possible, or served with no-store when a refresh is already allowed. A POST form with a JSON body is also supported and is never cached. 

curl 'https://tokens.stupidtech.net/v1/prices' \
  -H 'Content-Type: application/json' \
  --data '{
    "tokens": [
      { "chainId": 1, "address": "native" },
      { "chainId": 8453, "address": "0x833589fcd6edb6e08f4c7c32d4f71b54bda02913" }
    ]
  }'

One result per input, in input order, including duplicates. A valid batch returns HTTP 200 even when individual tokens are unavailable. 

{
  "currency": "usd",
  "prices": [
    {
      "chainId": 1,
      "address": "native",
      "status": "ok",
      "priceUsd": "2629.256297515841",
      "priceUpdatedAt": "2026-09-20T18:53:00.000Z",
      "marketCapUsd": null,
      "marketCapUpdatedAt": null,
      "fetchedAt": "2026-09-20T18:53:02.000Z",
      "nextRefreshAt": "2026-09-20T18:58:00.000Z"
    }
  ]
}
Status Meaning
ok Price available, source timestamp within 5 minutes.
stale Source timestamp older than 5 minutes; priceUsd is null.
not_found Chain and address are absent from the catalog.
price_unavailable No usable price from any source.
upstream_error A source request failed.
rate_limited A source throttled the refresh; retry after nextRefreshAt.

Notes

Prices refresh on demand, at most once per token per 5 minutes, shared across callers. Only ok carries a non-null price. Metadata and market caps are stored locally and search never contacts an upstream provider. Coverage is the CoinGecko-listed EVM catalog, so unlisted tokens return not_found.

Prices and market caps come from DefiLlama, GeckoTerminal, and DexScreener, merged with preference for the freshest usable source. DEX-derived prices require a minimum pool liquidity. Token metadata and images are sourced from CoinGecko; images use the largest available size (250×250).

Limits

Up to 50 tokens per price request, 100 search results per request, and a 32 KiB request body. The service is free and unauthenticated, so please cache responses and avoid tight polling.
